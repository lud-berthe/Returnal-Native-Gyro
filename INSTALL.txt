RETURNAL NATIVE GYRO + MIXED INPUT - 1.0.0
Source and changes: https://github.com/lud-berthe/Returnal-Native-Gyro

ENGLISH
1. Close Returnal completely.
2. Extract this archive into the game installation folder:
   .../steamapps/common/Returnal
   Merge the archive's Returnal folder with the existing one.
3. The three DLLs must be beside Returnal-Win64-Shipping.exe in:
   .../steamapps/common/Returnal/Returnal/Binaries/Win64
4. Launch normally. Open Settings > Controls > Gyro Configuration.

Do not overwrite a DLL belonging to another mod. Existing ReturnalGyro.ini
settings are preserved; defaults are created on first launch if absent.

Defaults: gyro ON, Aim Only, sensitivity X/Y 2.50, Player Space.
Flick Stick is OFF by default; its default spin duration is 150 ms.
With Steam Input, use a Gamepad layout and set Steam gyro behavior to None.
Steam calibrates its own motion stream. For direct sensors, use the native
Recalibrate Gyro footer and place the controller down during the countdown.

A selected physical gyro button acts on gyro immediately. Its native game
action fires on release only for taps shorter than 200 ms. Focused native
hold interactions retain their full hold. Stick means deflection, not click.

Uninstall: close the game and remove only version.dll, ReturnalGyro.dll
and SDL3.dll installed by this mod. Keep the INI to retain settings.
ReturnalGyro-Info may also be removed. Do not remove game folders.

FRANCAIS
1. Fermer completement Returnal.
2. Extraire cette archive dans le dossier d'installation du jeu :
   .../steamapps/common/Returnal
   Fusionner le dossier Returnal de l'archive avec celui deja present.
3. Les trois DLL doivent etre a cote de Returnal-Win64-Shipping.exe dans :
   .../steamapps/common/Returnal/Returnal/Binaries/Win64
4. Lancer normalement. Parametres > Controles > Configuration gyro.

Ne pas ecraser les DLL d'un autre mod. Les reglages ReturnalGyro.ini
existants sont conserves ; les valeurs par defaut sont creees si absent.

Par defaut : gyro active en Visee uniquement, X/Y 2,50, Repere du joueur.
Flick Stick desactive ; duree par defaut 150 ms.
Avec Steam Input : configuration Manette et comportement gyro Steam Aucun.
Steam gere sa calibration. En lecture directe : commande Recalibrer le
gyroscope dans le menu, puis poser la manette pendant le decompte.

Un bouton gyro agit immediatement sur le gyro. L'action native part au
relachement d'un appui de moins de 200 ms. Les interactions demandant un
maintien gardent leur fonctionnement. Stick = inclinaison, pas clic.

Desinstallation : fermer le jeu, retirer uniquement les trois DLL du mod.
Garder l'INI pour conserver les reglages. Le dossier ReturnalGyro-Info
peut aussi etre retire. Ne pas supprimer les dossiers du jeu.
